Nepa Romanized Pro 0.1.0

This package contains direct Unicode Romanized keyboards for Nepali (Devanagari), Nepal Bhasa (Newa/Prachalit), and Limbu (Sirijanga).

Use Shift for the shifted layer, Caps Lock for the Nepali conjunct layer, and Right Alt/AltGr for extended Newa and Limbu letters. On macOS, Right Option is the corresponding modifier.
